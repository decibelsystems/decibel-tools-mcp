# Baukunst Demo

## Summary

Live demo showcasing Decibel peer-to-peer workflow + productivity tools using NoiseVault as the vehicle. Ben drives with noisevault peer doing live work, decibel-tools peer on standby for support. Audience participatory element — someone suggests a band/genre and it gets added to the graph live.

## Motivation

- Showcase the Decibel peer-to-peer + tools workflow to a group
- Use a real project (NoiseVault) doing real work, not a contrived example
- Audience participation: someone picks a band/genre, it gets wired into the graph live

## Format

- Ben + noisevault peer do the live coding/data work
- Decibel-tools peer online and available for support, lookups, coordination
- NoiseVault builds in ~5 sec, deploys in ~30 sec — fast enough for live feedback

## Outcomes

- Audience sees real peer-to-peer collaboration on a real task
- Decibel productivity tools (sentinel, friction, etc.) used naturally during the session
- A new band/scene actually lands in NoiseVault's graph from audience input
